# Contexto del proyecto

Un estudio de diseno de producto acaba de ganar un contrato para reconstruir el frontend de una plataforma de alquiler vacacional. Antes de crear su propio sistema de diseno, el equipo quiere validar la arquitectura de componentes clonando una interfaz de produccion bien conocida: Airbnb.

La idea es usar este ejercicio para entender:

- que componentes de UI son necesarios,
- que datos necesita cada componente,
- y como se conectan esos componentes entre las distintas vistas.

## Rol dentro del proyecto

Te han incorporado como desarrollador frontend junior. Tu mision es implementar en Next.js, usando componentes de React, tres vistas clave de la experiencia de Airbnb.

## Vistas a construir

1. Pagina de inicio (Home).
2. Pagina de catalogo o resultados de busqueda.
3. Vista de detalle de una habitacion.

## Enfoque de trabajo

Para definir la arquitectura y los componentes, se utilizaran prompts de vision que convierten capturas de pantalla en especificaciones de componentes. A partir de esas especificaciones, se implementaran las vistas en Next.js.

## Objetivo tecnico

Construir una base de frontend reutilizable que permita:

- identificar patrones repetidos de interfaz,
- separar correctamente layout, secciones y componentes de UI,
- y preparar el camino para un sistema de diseno propio mas adelante.
